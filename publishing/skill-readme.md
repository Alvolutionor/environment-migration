# Environment Migration skill

Discover a working environment, prepare a verified migration package, and preview restoring selected files into independently mapped destination folders.

Install this folder as `environment-migration` in your agent's skills directory. Load [SKILL.md](SKILL.md), then ask your agent to prepare a migration package for a new computer. Requires Python 3.10 or later for the bundled file transport.

Run the synthetic demo from this folder:

```sh
python scripts/demo.py
```

See [transport commands and configuration](references/transport.md), [Privacy](PRIVACY.md), and the [MIT license](LICENSE). Archive contents are unencrypted. Native application imports, software installation, credentials, links, and filesystem-specific metadata require separate procedures.

Source, installation options, and support: https://github.com/Alvolutionor/environment-migration.
